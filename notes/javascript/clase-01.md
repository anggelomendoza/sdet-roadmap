# Clase 01 - Introducción a JavaScript

## Objetivos

- Comprender qué es JavaScript
- Aprender variables
- Conocer tipos de datos
- Utilizar operadores
- Aplicar condicionales

---

## Variables

Las variables permiten almacenar información.

```javascript
let nombre = "Anggelo";
```

---

## Tipos de datos

### String

```javascript
let nombre = "Anggelo";
```

### Number

```javascript
let edad = 35;
```

### Boolean

```javascript
let activo = true;
```

---

## Operadores

```javascript
10 + 5
10 - 5
10 * 5
10 / 5
```

---

## Condicionales

```javascript
let saldo = 1000;

if (saldo > 500) {
  console.log("Operación permitida");
}
```
